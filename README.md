# Namit Bhandula - Executive Personal Brand Website

Premium personal brand website for Senior Technical Recruiter specializing in global talent sourcing and recruitment operations.

## Features

- 🎨 Premium dark theme with cyan/blue accents
- ⚡ Smooth animations with Framer Motion
- 📱 Fully responsive design
- 🚀 Fast performance (Vercel deployment)
- 🌙 Dark/Light mode toggle
- ✨ Interactive sections with scroll animations

## Built With

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- next-themes

## Getting Started

```bash
npm install
npm run dev
